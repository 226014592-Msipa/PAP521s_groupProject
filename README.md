## Our Municipal Financial Management System comes with many functions such starting with the Main menu which navigates what you must do, following is the Employee Management and allows users to add or delete employees. It also contains the budget, supplier, asset and reports which also have the same function but different responsibilities according to how they're assigned.

##System Features
 Main Menu
-the main menu shows:
-Employee Management 
- Budget Management 
- Supplier Management 
- Asset Management 
- Reports 
- Exit
  
EMPLOYEE MANAGEMENT 
-Has Features of: 
- Add an employee. 
-Display employees. 
-Search for an employee. 
-Calculate employee salary information. 

 BUDGET MANAGEMENT 
-Gives option to: 
-Enter departmental budgets. 
-Enter expenditure. 
-Calculate remaining budget. 
-Determine whether expenditure is within budget.

 SUPPLIER MANAGEMENT 
-Adds suppliers. 
-Displays suppliers. 
-Allows you to Search for suppliers. 
-Compare/search supplier information.

   ASSET MANAGEMENT
 -STORES: Asset ID 
 -Asset name 
 -Asset type 
 -Purchase value 

  REPORTS
-Shows: Total allocated budget 
 -Total expenditure 
-Remaining budget
